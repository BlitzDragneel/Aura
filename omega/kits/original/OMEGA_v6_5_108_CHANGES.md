# OMEGA v6.5.108 — Neon Glow theme (look only)
- New theme **Neon Glow** (`neonglow`), now the default: night background, cyan/magenta/lime neon, glowing headings, cards,
  buttons, focused inputs and the Ω brand (slow pulse; off with Settings > Animations off or the phone's reduce-motion setting).
- A browser still on the old default "Dark" moves to Neon Glow once; any other theme you chose is kept. "Dark (classic)" is
  still in Settings > Display > Theme. The accent colour setting does not apply in Neon Glow (its cyan is fixed).
- No rule, engine, data or research text changed; CREED's engine is byte-identical (s102 with PREV = v6.5.107).
- Build: `python3 patch108.py <v6.5.107> <out>`. Tests: s108 (7/7); s102 6/6, s106 13/13, s107 6/6 on this build.
