Install OMEGA on your phone or computer

Android (Chrome): open OMEGA → menu ⋮ → Install app.
iPhone / iPad (Safari): open OMEGA → Share → Add to Home Screen.
Windows / Mac (Chrome or Edge): open OMEGA → the install icon at the right of the address bar (or menu → Install OMEGA).
Installed, it opens like an app, in its own window, and starts even offline; updates arrive by themselves the next time you open it online.
Or keep a copy: download the app file and open it in Chrome or Edge on your computer (your data stays in that browser).
